# 회원가입·리뷰 테스트 20건

원본 포트폴리오 기록을 재정리한 표입니다. 이번에 20건 전체를 다시 실행한 결과는 아닙니다. E01~E03은 별첨 포트폴리오의 대표 캡처 번호이며, 과거 실패 원본이 없는 항목은 미확보로 구분했습니다.
