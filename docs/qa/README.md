## 확인한 결함

- 가입할 때 입력한 생년월일이 DB에 저장되지 않는 문제
- 공백 금지 안내와 달리 공백 포함 비밀번호로 가입할 수 있는 문제

수정 후 생년월일 저장과 공백 차단을 다시 확인했습니다. 최초 실패 캡처는 미확보이며, 위 2026-10-19 자료는 새로 직접 실행한 결과입니다. 다른 가입 조건도 재확인했으나 정확한 회귀 항목과 건수는 남아 있지 않습니다.

테스트·SQL 초안, 코드 분석·수정, 문서 정리에 AI를 활용했습니다. 별도 AI 실행을 직접 수행한 20건에 합산하지 않았습니다.
