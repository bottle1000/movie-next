# 영화 평균 평점: 지원자 직접 검증 결과

2026-10-19 제출한 원본 캡처 7장을 대조했습니다. 지원자가 본인 프로젝트를 실행해 조작·캡처했고, AI는 제출된 화면과 SQL 결과를 검토했습니다. AI가 이 환경의 브라우저나 DB를 직접 실행한 결과가 아닙니다.

- 대상: `http://localhost:3000/movies/11`, 범죄도시, 영화 ID 11.
- 사전 데이터: 기존 admin의 3점 리뷰 1건(review_id=47, 내용 ddd). 표시된 작성일은 2025-11-19이며 이번에 새로 등록한 기준 리뷰가 아닙니다.
- 추가 리뷰: qa-a 1점(review_id=61, qa-a-test), qa-b 5점(review_id=62, qa-b-test). 화면 작성 시각은 각각 2026-10-19 14:53:26, 14:54:11입니다. 작성 시각을 캡처 시각으로 간주하지 않습니다.

| 단계 | 점수 | 기대 평균 | 화면 평균 | 화면 리뷰 수 | SQL 건수 / 평균 | 판정 |
|---|---|---:|---:|---:|---|---|
| ① 기존 admin 리뷰 | 3 | 3 | 3 | 1 | 캡처 미확보 | 화면 일치 |
| ② qa-a 등록 후 | 3, 1 | 2 | 2 | 2 | 캡처 미확보 | 화면 일치 |
| ③ qa-b 등록 후 | 3, 1, 5 | 3 | 3 | 3 | 3 / 3 | 화면·SQL 일치 |
| ④ qa-a 삭제 후 | 3, 5 | 4 | 4 | 2 | 2 / 4 | 화면·SQL 일치 |

③의 SQL에는 리뷰 47·61·62가 있고, ④에는 47·62만 남았습니다. qa-a의 1점 리뷰가 사라지고 admin·qa-b 리뷰가 유지되었으며, 평균이 3에서 4로 변경된 결과를 확인했습니다. ①·②의 DB 결과는 추정해서 채우지 않았습니다.

## 범위와 한계

이 4단계 시나리오의 화면 평균은 모두 기대값과 일치하며, ③·④ 단계는 SQL과도 일치합니다. 모든 평점 조합·권한·동시성의 정확성까지 입증하지 않습니다. 삭제 확인창과 실제 클릭 순간, 삭제 수행 계정은 이 캡처만으로 확정하지 않습니다. 이번 실행의 소스 해시·브라우저 버전은 미확인입니다.

이번 자료는 새 직접 실행 결과입니다. 기존 35건에 합산하지 않으며, 과거 문서의 3.666… 값을 소급해 수정하거나 당시 원인을 확정하지 않습니다. 과거 원본이 없는 부분은 그 한계를 남깁니다. 앞선 AI 저장소 함수 검증 및 임시 환경의 기준 화면과도 별도 기록합니다.

## 포트폴리오 반영 문장

기존 3점 리뷰가 있는 영화에 계정 A의 1점·B의 5점 리뷰를 순서대로 등록한 뒤 A 리뷰를 삭제하는 4단계 시나리오를 직접 수행했습니다. 화면 평균 3→2→3→4를 확인하고, 삭제 전후 SQL의 리뷰 목록·건수·평균을 대조해 A 리뷰 삭제와 다른 리뷰 유지, 평균 재계산 결과가 일치함을 확인했습니다.
